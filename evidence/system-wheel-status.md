# 0.2 通用滚轮验证记录

当前实现遵循普通鼠标滚轮的路由，不锁定浏览器或前台窗口。这份记录只对应 0.2.0 / build 2，不能沿用 0.1 测试窗口的滚动结果。

| 层级 | 本轮证据 | 不能据此断言 |
| --- | --- | --- |
| 自动测试 | 20 项通过，包含双方认证、篡改／重放、旧会话、暂停、过期、小数和输出前资格失效 | 真实表冠手感或锁屏行为 |
| 独立审查 | 发现的输出资格变化问题已修复并复核；没有遗留代码阻断项 | 安全协议已获正式审计 |
| Mac 构建与安装 | Xcode 27 开发签名成功；0.2.0/2 已替换到固定安装位置；严格签名通过，profile 授权 keychain group | 所有电脑都能安装或正式分发 |
| Mac 密钥 | 实际导入到数据保护钥匙串成功，应用删除导入文件；无交互读取状态成功 | 真实锁屏时该条目一定不可读 |
| Watch 构建与安装 | 开发签名通过，描述文件包含目标 Watch；CoreDevice 返回安装成功，密钥导入文件复制成功 | Watch 应用已经运行并导入密钥 |
| Watch 启动 | 自动启动被系统明确以 Locked 拒绝，等待使用者解锁进入应用 | 认证链路或系统滚动通过 |
| 系统输出 | 代码已接入 CGEvent；权限、浏览器、非浏览器、后台、暂停与锁屏真机测试待完成 | 发送回执等于目标区域已滚动 |

安装期间的本地设备代理例外已恢复。原始构建、签名、设备回执和密钥均在本机被 Git 忽略的私有目录，不公开。开发安装的账号与系统授权仍由设备拥有者完成。
