# 0.3 练习、独立盲指与真机证据

本页对应 #5，集成入口为 #2 / Draft PR #6。G0 合同为 `2d5dbf025ec35ef73d225b55a0edaf2e42092e07`。源码实现、自动测试、实际安装、真实任务和个人偏好分别记录；练习窗口中的圆点移动不能证明浏览器或 Finder 已接受系统输入。

## 当前交付边界

- `PointerPractice.swift` 是窗口实际使用的评分器：确定性随机目标、练习与正式分组、模式顺序轮换、分段计时、失误记录、一次锁定的独立盲指和 JSON 证据。
- `PracticeWindow.swift` 是 AppKit 自有窗口；不调用 CGEvent、不自行采样、不读其他应用。它接收主线传入的模拟指针、点击、冻结与姿态。
- D 盲指直接复用 `StableAttitudeCollector` 和已标定模型的 `predictRaw`，没有另一套拟合代码。自动测试验证的是这些生产类型的行为。
- 截至本包初始交付，练习模块与窗口已在独立 scratch 目录编译，评分与移动周期测试通过。最终 app 构建、窗口现场操作、真实手势、真实应用、四模式偏好均需要主线的同版集成和实际反馈；不得据此勾选整体验收通过。

## 主线接入

打开前先由主线停止当前移动，进入 `.practice` 隔离范围；调用窗口并不替代输出资格检查。窗口关闭时主线停止、清理旧运动并回到阅读态，不能恢复此前移动。scope 请求仅在主线完成后生效，不能由窗口假定外部系统已经停下。

```swift
let practice = PracticeWindowController(screen: screen, appKitFrame: appKitFrame)
practice.metadataProvider = { PracticeMetadata(
    runID: runID, macBuild: macBuild, watchBuild: watchBuild, sourceSHA: installedSHA,
    posture: "固定坐姿 / 前臂支撑", transport: transportDescription,
    modeParameters: actualModeParameters) }
practice.onSelectMode = { mode in /* 主线先停再切换 */ }
practice.onScopeChange = { scope in /* 主线换会话 → 设置范围 → 发布最终状态 */ }
practice.onFreezeMovement = { /* 明确请求冻结 */ }
practice.onClose = { /* 结束隔离，回阅读态；不自动开始移动 */ }
practice.configureBlind(
    binding: model.binding, calibrationID: model.calibrationID,
    trainingTargets: PointingCalibration.targets,
    prediction: { sample, screen in try model.predictRaw(sample: sample, screen: screen) })
practice.showWindow(nil)
```

接收到共同映射的相对／绝对结果后，主线用同一 `PointerScreen` 完成单屏裁剪，再调用 `move(to:)`。明确停止、点击前、首次表冠冻结时同步调用 `freeze()`；完整点击提交给 `click(at:button:clickCount:)`。独立盲指的姿态交给 `ingest(sample:)`。窗口内计时统一使用 Mac 单调时钟；采样稳定性只比较 Watch 自己的时间，不跨设备相减。

所有点都是 Quartz 全局逻辑坐标，x 向右、y 向下；Retina 的 scale 不乘到目标直径或坐标。窗口覆盖传入屏幕的 AppKit frame，使用翻转视图显示；目标避开顶部说明和底部控制区，JSON 中保存实际测试区域，不能把这个区域描述成全部屏幕像素。

## 简短操作清单

1. 主开发安装同一次构建的 Mac/Watch，记录实际 build 与源码 SHA。只保留一个已安装 Mac 实例，脱离 Xcode 调试器运行。按应用和系统提示授予发送事件所需权限；不能以测试注入函数的放行代替真实权限。已有配对继续使用，重新签名不重置配对密钥。
2. 先在 Watch 主控页用可见按钮开始／停止移动，确认 A 基本可用；再用食指和拇指互点两下进行同一操作。真正指向电脑的姿势下验证，不能只在抬腕看表时验手势。
3. 对准后先冻结，再点击。冻结仍允许表冠和点击；总暂停禁止全部输入。点击或第一次表冠输入也会先冻结，结束后需要明确再次开始移动。
4. 同一安装版直接选择 A/B/C/D。A 用水平转向和上下朝向变化跟手；B 用前臂内外翻转控制左右；C 像摇杆，偏离中立持续移动、回中停止；D 是固定坐姿下把手腕朝向换算到单屏位置，需要五点标定。
5. D 标定前固定坐姿、前臂支撑和佩戴。按五点提示采集稳定姿态，再进行九点独立盲指。换参考系、显示布局或佩戴后旧标定无效；普通冻结可以复用仍有效的模型。
6. 练习与标定窗口内动作隔离。退出后按主线提示回阅读态，再开展真实应用任务。发生连接、权限或参考变化时停止记录该故障，恢复后不期待补放旧动作。

安装与回退由 #2 负责。回退使用保留的 `rollback/0.2-253ff29` 源码在独立目录重新签名；旧过期安装包不算有效回退收据。本包不安装、不重置系统权限或钥匙串。

## 同版比较

先完成每个模式的少量练习，把默认速度调到基本可用并记录实际参数。B/C 不因明显不合适的起始参数被提前判差。所有模式保持同一屏幕、姿势、传输设置；改变参数或模式会中止并保留当前轮；每轮开始重新读取实际参数和构建信息，不复用开窗时的旧快照。

- 选择练习：4 个目标，不进入正式比较。
- 选择正式：每模式 20 个随机目标。直径 24 / 48 / 96 逻辑单位，数量为 7 / 7 / 6；这些是比较起点，不是行业标准。
- 正式建议顺序随比较轮次轮换：轮次 0 为 A→B→C→D，1 为 B→C→D→A，依此类推。界面提示顺序，使用者按顺序选择模式；JSON 保存计划顺序与每轮实际模式，导出数组保留实际完成顺序。一次轮换不能完全消除熟练或疲劳。
- 界面的“目标顺序编号”（随机种子）相同时产生相同目标序列，便于同任务对照。若担心记忆效应，下一比较轮换新种子；把种子与顺序一起记录，不在看到成绩后挑选有利目标。
- 每个目标出现即开始计时，最多 30 秒。完成后停 0.8 秒再显示下一个；需要重新明确开启移动。第二组双击事件不能自动完成下一目标。
- 普通鼠标／触控板可做一次参照，只接受自有窗口的原生鼠标输入，不观察其他应用。
- 完成后填写 0–10 的主观费力与具体观察；空值表示未反馈。不要替使用者选出“最自然”模式。

### 计时如何解释

`totalSeconds` 是目标出现到命中、超时、跳过或中止的完整耗时，包含开启、看表、冻结与修正。`firstTargetEntrySeconds` 是目标出现到指针首次进入圆内；它只表明到过，不能替代最终成功。`firstFreezeSeconds` 是第一次冻结发生的时刻，`freezeToCompletionSeconds` 包含此后到完成的全部时间，包括冻结后重新移动修正。

主线明确调用 `freeze()` 才算观察到了冻结时刻；只有点击时隐式冻结的样本标记 `explicitFreeze=false`，不把其接近零的数值混入“冻结到点击”摘要。鼠标参照通常属于这一类。首次点击是否命中、误击次数、目标再次进入次数、冻结后重新移动次数分别保存，不把这些不同动作合成一个难解释的“修正分数”。

完成时间摘要使用成功目标的中位数、最小和最大，同时给出已尝试、成功、失败数量。超时／跳过／中止和错误按钮全部保留；未开始的目标保留在计划列表中而不冒充失败或成功。不报小样本 p99，不用成功样本的快速度掩盖失败率。

## D 独立盲指

盲指检验的是“不看预测落点，按自身感觉指向目标”的能力；看着光标不断修正检验的是另一种能力。两者必须分开写结论。

1. 使用已经完成的 D 模型。选择“原姿势”，在实际测试区域的九宫格位置生成 9 个目标，覆盖中心附近、边缘和角落，随机顺序；与每个训练点至少相隔一个目标直径。中心若与训练点冲突，预先用固定偏移替换，不根据模型预测挑点。
2. 自有练习指针隐藏，只显示目标。稳定指向后按“已指向，锁定稳定样本”。G2 已将 Watch 左击路由为这个内部锁定动作；实际设备效果待测，不向系统提交盲指点击。触发后留 150 ms 再采集，减小触碰动作的影响。随后用 #4 同一个采集器收集至少 0.5 秒和 10 个连续稳定样本；5 秒内无法完成的目标记失败。
3. 用平均姿态调用生产模型的 `predictRaw`，先把结果锁入评分器，再画落点。下一次输入不能修改当前成绩，必须明确选择下一个目标。失稳、上下文变化或拒绝预测都保留失败，不把失败重采后的成功覆盖回原目标。
4. 误差使用未裁剪的全局预测与目标中心之间的距离。预测落到屏幕外时，不能先裁到边界再计算误差。保存中位／最大误差、命中数、已尝试数、计划数、48 逻辑单位直径、屏幕／测试区域、calibrationID 与稳定样本统计。
5. 稍微改变坐姿或支撑点，再选择“姿势扰动”跑另一组，保留同一模型以测试这次改变的影响。若参考系／屏幕／佩戴已变，模型应失效，应重新标定并换 calibrationID，不能将其当作同一模型的姿势扰动结果。

允许结论是“区域定位有用，小目标不足”或“固定支撑可用，姿势改变后明显变差”。这些数据不支持无条件三维食指追踪的宣称。

## 自动测试与关键故障

运行本包评分测试：

```sh
swift test --scratch-path /tmp/wrist-practice-validation-build --filter 'Pointer(Practice|Output)Tests'
```

测试直接调用生产 `PointerPracticeRun`、`BlindPointerPractice` 和 `MovementLease`。包括确定性随机目标／逻辑坐标、完整计时、失误修正、迟到双击、失败分母、时间倒退、JSON 记录、独立盲指单次锁定与未裁剪误差、停止早于确认、点击屏障、切模式、暂停恢复与新会话拒绝旧姿态。

`PointerOutputTests` 使用生产 `SystemPointer` / `PointerCoordinator`，只替换权限、当前光标和提交函数；不把另写一套正确的输出算法当实现。覆盖首击立即、第二触只新增第二对、网络迟到与位置改变、重复与重连、down 后失去资格仍尝试有限 up 清理、点击先冻结、旧周期、隔离 scope 标签、屏幕边缘反向及断流／设置／资格恢复。`SystemPointer` 拒绝一次点击后必须清掉双击候选，避免权限恢复后的下一击被误标为第二击。提交函数返回失败时不重发点击；有限释放的尝试并不是操作系统已经释放的真机证据。真实应用效果仍单独验。

## 一轮集中真机验收

先做 G1 的 A＋点击，不等四模式全部完成。只有必须人执行的实体动作和系统确认留给使用者；等待期间继续独立构建和自动测试。

1. **版本与实例**：记录 Mac build、Watch build、两者源码 SHA、实际系统版本和签名有效期；脱离调试器，确认只有一个已安装 Mac 实例。
2. **A 最早闭环**：Watch 可见按钮和互点分别开始／停止，浏览器真实链接单击或 Finder 文件打开；确认只是冻结时表冠仍可阅读。
3. **实际点击任务**：浏览器长文点链接，移回正文再滚动；Finder 左击选中、两次触摸双击打开；右击菜单，重新开移动定位菜单项，再停止并选择。记录目标应用是否真的执行，不能只记“CGEvent 已提交”。
4. **姿势与阅读**：真正指向电脑时互点；B 是否触发系统翻腕；为了看表点击是否转腕偏移；放松阅读一段再继续。记录系统前台／放腕限制及伸手、看表、注意力中断。
5. **安全恢复**：总暂停／继续、亮屏锁定／解锁、撤销／恢复权限、蓝牙断开／重连、Mac/Watch 重启。恢复后无旧动作，D 参考重建后旧模型不继续生效。
6. **四模式同版**：无需重装或改文件切换 A/B/C/D，先练习，再按轮换顺序正式记录；原姿势与扰动盲指独立保存。
7. **后台行为**：腕控最小化或后台，普通应用切换后仍能操作真实应用；标定／练习期间确认没有外部实验动作。

任何停止排序、重复点击、恢复补放或资格绕过都是阻断项。性能软目标未达到则记录实际值与体感，不为凑数字修改验收口径。
