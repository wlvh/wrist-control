# 腕控 WristControl · 通用滚轮开发版

把 Apple Watch 数码表冠当作 Mac 的普通上下滚轮：**鼠标放在哪里，表冠就在那里滚动。** Mac 通过公开的 `CGEvent` 接口发送滚轮事件，macOS 决定接收区域。浏览器只是验收场景；程序不识别浏览器、不锁定窗口、不移动鼠标、不抢焦点。

手表与电脑通过 CoreBluetooth 直接通信。运行时没有手机或网络中继、云服务、脚本服务；开发安装仍需要 Xcode。电脑窗口可以退到后台或最小化。手表按钮和电脑按钮均可暂停／继续，电脑应用每次启动默认暂停。

## 当前证据

0.2 版两端开发签名构建与安装已完成，共享逻辑和电脑输出规则共 20 项测试通过；Mac 受保护钥匙串实际导入与无交互读取通过。真实浏览器与非浏览器滚动、后台与锁屏表现仍在验证，**尚不能写成已经通过**。

此前 0.1 版在真实 Watch 上完成过表冠 → BLE → 自有文章窗口链路，电脑记录 537 条滚动、25 条停手和 3 条标记。那是旧版测试窗口的证据，不能替代系统滚轮验收。参见[历史证据](evidence/STATUS.md)和[电脑、手表与手机互联笔记](docs/device-connection-notes.md)。

## 构建与安装

1. 使用支持真实设备系统的正式版 Xcode。复制 `Config/Local.xcconfig.example` 为被忽略的 `Config/Local.xcconfig`，填入自己的 Team ID 和独立 bundle 前缀。在 Xcode 中登录相应开发账号，保持已有证书和私钥。
2. 打开 `WristControl.xcodeproj`，构建 `WristControl` 和 `WristWatch`。Mac 采用本地开发签名、不启用 App Sandbox，需要允许本应用访问数据保护钥匙串的开发描述文件；手表同样需要有效的真机描述文件。**无签名编译或临时签名不是可使用版本。**
3. 安装电脑应用到固定位置，只运行这一份；将手表应用安装到已配对、启用开发者模式的 Watch。两端安装同一版本，旧的未认证协议不能控制本版本。
4. 开发安装者按[单对设备配置](docs/system-wheel.md)给两端装入同一份随机密钥。密钥在应用的受保护钥匙串中保存，不进入源码、通用应用包或 Git；导入文件在应用验证保存成功后删除。
5. 打开 Mac 腕控，点“允许滚轮权限”，由设备拥有者在系统设置 → 隐私与安全性 → 辅助功能中允许腕控。打开手表腕控，设备认证完成后点“继续滚轮”。

这轮仍是开发安装，不是面向陌生用户的一键配对或正式分发。账号登录、系统密码和权限确认由设备拥有者完成；不要重置旧 login 钥匙串。未完成签名、密钥配置或权限时，程序停止输出并给出状态，不降级为未认证控制。

不签名编译和共享测试：

```sh
swift test --disable-xctest --enable-swift-testing
xcodebuild -project WristControl.xcodeproj -scheme WristControl -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO build
xcodebuild -project WristControl.xcodeproj -scheme WristWatch -destination 'generic/platform=watchOS' CODE_SIGNING_ALLOWED=NO build
```

`Scripts/generate-project.py` 可重新生成工程。`Scripts/build-mac.sh` 使用相同的 Xcode 开发签名流程，不再提供临时签名降级。

## 真机验收

脱离 Xcode 调试器，从安装位置启动两端应用。把指针留在浏览器长文正文，慢转、快转、停手、立即反转。然后在至少一个非浏览器应用（例如文本编辑）重复；再把腕控最小化后重复。仅用快捷键切换应用而不移动指针时，不承诺目标跟随前台应用。

按一次暂停，确认不再滚动；继续后只执行新的转动。分别测试 30 秒、1 分钟、3 分钟阅读停顿，放下手腕，切出手表应用后返回，以及蓝牙断线重连。屏幕仍亮着的锁屏、唤醒但尚未解锁、权限撤销必须单独测试，不能用显示器睡眠替代锁屏验收。

点电脑“导出诊断”保存结果，访达会选中文件；缺少手表日志会明确标记。日志里的“已发送到系统”不代表目标区域已滚动。两端时间戳不能直接相减，实际画面延迟仍需同一镜头拍摄判断。

## 实现边界

- `WatchApp/`：SwiftUI 表冠输入、暂停按钮、前台蓝牙连接。
- `MacApp/`：BLE 服务、公开系统滚轮输出、权限与受保护数据检查、编号长文测试面板。
- `Shared/Sources/WristCore/`：线性映射、会话与过期动作、消息认证和密钥存储。
- `Tests/WristCoreTests/`：输入、消息认证、防重放、暂停和断线规则。

不加入惯性、自动滚动、横向滚动、键盘、任意程序执行、应用白名单、浏览器扩展或后台保活。手表进入非活动状态仍主动停止扫描和连接；真实阅读中是否频繁需要唤醒，仍需反馈。只控制已配置的一对设备，完整配对与正式分发另行开发。
